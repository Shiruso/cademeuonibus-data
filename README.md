# Cadê Meu Ônibus

Um aplicativo para ajudar usuários a localizarem ônibus em tempo real (ou baseado em horários GTFS).

## 🚀 Sobre o Projeto

Este é o meu primeiro projeto Android, desenvolvido para facilitar a vida de quem utiliza o transporte público.

## 🛠️ Tecnologias Utilizadas

- Kotlin
- Jetpack Compose
- Retrofit / OkHttp (para rede)
- GTFS (General Transit Feed Specification)

## 📦 Como rodar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/CadeMeuOnibus.git
   ```
2. Abra no Android Studio.
3. Certifique-se de ter o arquivo `gtfs.zip` (se necessário) na pasta raiz ou siga as instruções de configuração.
4. Compile e rode no seu dispositivo ou emulador.
